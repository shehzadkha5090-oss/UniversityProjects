Lab 9: Time-Series Forecasting with Concept Drift
Dataset: UCI Student Performance (student-por.csv), 649 rows x 33 cols, semicolon-delimited

CAVEAT: There is NO date/timestamp column and no true seasonal series in this
dataset, so this is a SIMULATION, not real time-series forecasting. File order
is used as a pseudo-time order only.

Batching: 649 rows split into 7 sequential batches in file order (6 x 100 + 49),
the same batching as a streaming setup. Forecasting starts at batch 1 because
for batch 0 there is no prior data.
Features: all columns except G3. Target: G3 (regression, primary) plus
pass = (G3 >= 10) derived from it. Preprocessing: numeric median-impute +
StandardScaler, categorical most-frequent-impute + OneHotEncoder(handle_unknown='ignore'),
fit on data seen so far only.

Concept drift between consecutive batches:
Method: two-sample Kolmogorov-Smirnov (KS) test on G1 and on G2 between consecutive
batches, threshold p < 0.05 (drift flagged if p < 0.05 on either variable), plus the
rolling pass-rate / mean-G3 shift (current batch minus previous batch).
